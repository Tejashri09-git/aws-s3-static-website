# AWS S3 Static Website

## Project Description
A static website deployed and hosted using Amazon S3.

## Technologies Used
- HTML
- CSS
- JavaScript
- Amazon S3

## Project Steps
1. Created an S3 bucket
2. Enabled static website hosting
3. Uploaded HTML, CSS and JavaScript files
4. Configured public access using bucket policy
5. Accessed the website using the S3 website endpoint
